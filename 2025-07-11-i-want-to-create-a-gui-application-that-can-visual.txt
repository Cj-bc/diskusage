  Project Analysis & Technology Selection

  For a cross-platform GUI application that visualizes directory space usage, I recommend Rust with the egui GUI framework because:

  1. Cross-platform compatibility: Runs natively on Windows, Linux, and macOS
  2. Performance: Fast directory traversal and efficient memory usage
  3. Single executable: No runtime dependencies
  4. Modern UI: Immediate mode GUI with good visualization capabilities
  5. Allowed language: Follows your language preferences (Rust is in your allowed list)

  Application Features

  The application will include:

  1. Directory Browser: Navigate and select directories to analyze
  2. Space Analysis: Calculate directory sizes recursively
  3. Visualization Options:
    - Treemap visualization (rectangles proportional to size)
    - Tree view with size information
    - Pie chart for immediate subdirectories
  4. Interactive Features:
    - Click to drill down into subdirectories
    - Sorting options (by size, name, type)
    - Search/filter functionality
  5. Export Options: Save analysis results as JSON/CSV
  6. Cross-platform file system handling
